# Firmware: AI pipeline (AI-SED 2026, ITESCA PCB Lab)

`src/ai_pipeline.c/.h`: one 1024-sample window (13.333 kHz) -> 22 features -> MLP 22-32-16-4 -> class + probabilities.
Pure C99, no dynamic memory, float32. `include/modelo_pesos.h` is generated by `model/modeloCWRU_corregido.py`.

* On the STM32F411CE build with `-DAI_USE_CMSIS_DSP` (uses `arm_rfft_fast_f32`). Without it a portable FFT is used.
* Status: verified on a PC against the Python reference (`test/`). Not yet flashed or timed on the microcontroller.
* Still to do: SPI driver for the IIS3DWB, 2:1 decimation (26.667 -> 13.333 kHz), USART1 link to the ESP32-C3.

Test (needs the CWRU .mat files): `python3 test/export_ref.py` then
`gcc -O2 -std=c99 -o test/test_pipeline test/test_pipeline.c src/ai_pipeline.c -lm && ./test/test_pipeline`
